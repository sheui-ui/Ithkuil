# Ithkuil
这是一个关于Ithkuil系列的小工具，有用，但不多  
由于cmd显示不了这些字符（会有乱码），所以要使用这些工具，需要VS code，然后把代码复制到里面，然后才能运行  
一般来说，工具会有中文和英文两个版本，如果只有一个版本，那它大概率是中文版  
本人是学生党，所以更新频率不固定

This is a collection of small tools for the Ithkuil series; they’re useful, though there aren’t many of them.  
As the Command Prompt cannot display these characters (they’ll appear as garbled text), to use these tools you’ll need VS Code; copy the code into it before you can run it.  
Generally speaking, the tools come in both Chinese and English versions; if only one version is available, it’s most likely the Chinese version.  
I’m a student, so the frequency of updates is irregular.
